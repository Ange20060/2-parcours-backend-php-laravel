# 🔵 Niveau 10 — API REST & Authentification

Le savoir-faire le plus recherché d'un backend : concevoir des **API RESTful** propres,
sécurisées et documentées, consommées par des applis web/mobiles.

> 🎯 **Objectifs :** principes **REST** · **API Resources** (formater le JSON) · authentification
> par **token** avec **Laravel Sanctum** · pagination, filtres, versionnement · codes de statut
> HTTP corrects · gestion des erreurs JSON.
