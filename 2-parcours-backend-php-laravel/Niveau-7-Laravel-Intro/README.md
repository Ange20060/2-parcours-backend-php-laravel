# 🔵 Niveau 7 — Introduction à Laravel

Enfin **Laravel** ! Fort de tes bases PHP, POO et des principes, tu vas découvrir le framework
backend le plus populaire — et comprendre **pourquoi** il est conçu ainsi (il applique les
principes que tu connais déjà).

> 🎯 **Objectifs :** installer Laravel (Composer) · l'architecture **MVC** · le **routing** ·
> les **contrôleurs** · les vues **Blade** · la ligne de commande **Artisan** · le conteneur de
> services et l'**injection de dépendances**.
