# 🏆 Niveau 12 — Architecture & Projet final

Le grand final : rassembler **tout** le parcours dans une **vraie application backend Laravel**,
bien architecturée, testée, versionnée et déployée. La pièce maîtresse de ton portfolio de
développeur backend.

> 🎯 **Objectifs :** organiser une application (couches, services, repositories) · appliquer
> les **design patterns** utiles · déployer · documenter · livrer un projet **professionnel**
> qui respecte **tous** les principes du parcours.

## 🧩 Idées de projet final (au choix)
- **API de gestion de tâches d'équipe** (auth, rôles, projets, tâches, commentaires)
- **API de mini-boutique** (produits, panier, commandes, stock, paiement simulé)
- **API de blog / CMS** (articles, catégories, utilisateurs, modération)

## 🚀 Le cahier des charges type
- Architecture claire (contrôleurs fins, services, repositories)
- Base de données modélisée (migrations, relations, seeders)
- API RESTful sécurisée (Sanctum), validée (Form Requests)
- **Tests** automatisés (fonctionnels + unitaires) qui passent
- Code respectant DRY, KISS, SoC, SOLID… (revue à l'appui)
- Dépôt **GitHub** propre (commits clairs, `README`, instructions d'installation)
- **Déploiement** en ligne (bonus)
