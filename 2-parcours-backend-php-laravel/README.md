# 🐘 Devenir Développeur Backend — PHP & Laravel

Parcours structuré pour devenir **ingénieur backend** avec **PHP** puis **Laravel**. On part
**de zéro sur PHP**, mais avec une exigence d'**ingénieur** dès le départ : on n'apprend pas
seulement à « faire marcher » du code, on apprend à écrire du code **propre, maintenable et
professionnel**.

> 🎯 **Public** : étudiant·e de 2ᵉ année, à l'aise avec la logique de programmation, qui vise
> un métier de **développeur backend**. Le rythme est plus soutenu qu'un cours grand débutant.

---

## 🧠 La philosophie de ce parcours

Un bon développeur backend, ce n'est pas quelqu'un qui connaît le plus de syntaxe. C'est
quelqu'un qui écrit du code que **d'autres humains** (et son futur soi) peuvent lire, modifier
et faire évoluer **sans tout casser**. Deux piliers guident tout le parcours :

1. **Les fondamentaux du langage** (PHP, puis Laravel) — le « comment ».
2. **Les principes du génie logiciel** (DRY, KISS, SOLID…) — le « bien faire ».

> 📐 Les [**Principes du Génie Logiciel**](./Principes-Genie-Logiciel/) sont un **domaine
> transversal** : on y revient à **chaque niveau**. C'est ce qui sépare un codeur d'un ingénieur.

## 📚 Les deux façons de lire ce parcours

- **En vertical (par niveau)** : tu suis 1, 2, 3… pour monter en compétence progressivement.
- **En transversal (par domaine)** : le domaine [Principes du Génie Logiciel](./Principes-Genie-Logiciel/)
  se consulte **en parallèle** de tous les niveaux, comme une **boussole**.

---

## ✅ Méthode de travail (exigence d'ingénieur)

1. **Lis** la leçon, puis **recode** chaque exemple toi-même (jamais du copier-coller passif).
2. **Fais les exercices** sans corrigé. Un exercice « backend » n'est pas fini quand « ça
   marche », mais quand le code est **propre**.
3. À chaque exercice, demande-toi : *« Quel principe du génie logiciel s'applique ici ? »*
4. **Versionne avec Git** dès le Niveau 1. Commits petits, messages clairs.
5. **Applique la règle du Boy Scout** : chaque fois que tu touches un fichier, laisse-le un
   peu plus propre qu'avant.
